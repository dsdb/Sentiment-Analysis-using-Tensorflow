Overview

Sentiment analysis empowers us to decipher the sentiments, attitudes, and opinions expressed in written communication.

Fine-tune a pretrained transformer model for sentiment analysis using Tensorfolw Keras with Hugging Face

For a sentiment analysis transfer learning model on a pretrained BERT model, will remove the head that classifies mask words, and replace it with the sentiment analysis labels.

App URL - https://db-sentimentanalysis.streamlit.app/
